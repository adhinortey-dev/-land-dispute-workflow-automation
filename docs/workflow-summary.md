# Workflow Summary

This project models a digital land dispute and lease application workflow for an academic land administration scenario.

## Main Workflow Stages

1. Applicant submits a land dispute complaint or lease request.
2. The form records applicant information, parcel/title details, dispute type, supporting documents, and declaration.
3. A map panel supports spatial input using OpenLayers and OGC services.
4. Lots or areas of interest can be selected from web map layers.
5. Survey, recommendation, accountancy, record update, and outcome forms support back-office review.
6. The workflow supports structured movement from intake to analysis and final decision.

## GIS Integration

The land dispute complaint form includes JavaScript that connects to OGC web services and creates an interactive OpenLayers map. The map supports base layers, administrative layers, lot selection, coordinate capture, and form-field updates from selected spatial features.

## Academic Data Note

The forms and records are instructional/demo materials created for academic training. They are included to demonstrate workflow design, digital form structure, and geospatial process integration.
